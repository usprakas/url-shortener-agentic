# Scenarios

The checked-in generated result is `artifacts/demo-report.md`.

- Greenfield: a requirement flows through design approval, parallel implementation/test/docs, security, and release approval.
- Brownfield: link expiry analysis records the affected downstream subgraph: implementation, tests, docs, security, and release; the scenario records re-approval after invalidation.
- Ambiguous: “make links safer” is normalized with recorded assumptions: HTTP(S)-only URLs, private/localhost denial, and mandatory security approval.
