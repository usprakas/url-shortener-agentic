# Agentic URL Shortener

A Java 21/Spring Boot URL shortener paired with a governed SDLC orchestration prototype. Run `./mvnw clean verify` then `./run-demo.sh`. The service starts with `./mvnw -pl shortener-service spring-boot:run`; OpenAPI is at `/swagger-ui.html`.

The demo is offline and reproducible. `ANTHROPIC_API_KEY` only selects the optional agent adapter; no key is required or recorded.
