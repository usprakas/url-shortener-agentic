# Agentic URL Shortener

A Java 21 / Spring Boot 3 URL shortener, plus a governed SDLC orchestration prototype that drives
requirements → design → implementation/tests/docs → security → release through an explicit,
policy-gated DAG with human approval checkpoints, bounded retries, rollback, a kill switch, and
dynamic re-planning. See ARCHITECTURE.md for how it fits together and SCENARIOS.md for real
output from the three required scenarios (greenfield / brownfield / ambiguous).

## Requirements

- Java 21 (the bundled `./mvnw` wrapper handles Maven itself)
- Nothing else — the demo and test suite run fully offline with no external services or API keys.

## Setup from a clean clone

```sh
git clone <this-repo-url>
cd url-shortener-agentic
./mvnw clean verify
```

That builds and tests all five modules (`shortener-service`, `orchestrator-core`, `policy-engine`,
`agents`, `orchestrator-api`). See TESTING.md for exact test counts per module.

## Run the orchestration demo

```sh
./run-demo.sh
```

Runs all three scenarios end to end and writes:
- `artifacts/demo-report.md` — a combined report with per-scenario and aggregate status, policy
  verdict, success rate, retry/rollback/re-plan counts, per-stage and end-to-end latency, and MTTR.
- `artifacts/audit/<runId>.events.jsonl` — the append-only audit trail per run (actor, event type,
  timestamp, input/output hashes, rationale, and per-gate policy results).
- `artifacts/<runId>.artifacts.json` — the full, un-hashed content each stage actually produced,
  so you can see exactly what was generated instead of only its hash.

`artifacts/` is gitignored; it is meant to be regenerated by running the demo, not shipped as a
static file in the repo. SCENARIOS.md quotes its content from one such run.

## Run the shortener service itself

```sh
./mvnw -pl shortener-service spring-boot:run
```

Then:
- `POST /api/v1/links` — create a short link (`{"url": "...", "alias": "optional", "expiresAt": "optional"}`, optional `Idempotency-Key` header)
- `GET /{code}` — 302 redirect
- `GET /api/v1/links/{code}` — metadata
- `GET /api/v1/links/{code}/stats` — click count, timestamps, referrer breakdown
- `DELETE /api/v1/links/{code}` — soft delete
- `GET /swagger-ui.html` — interactive OpenAPI UI; `shortener-service/openapi.yaml` is a static
  snapshot of the same spec, fetched from a running instance (`/v3/api-docs.yaml`) rather than
  hand-written.
- `GET /actuator/health` — liveness/readiness

## Optional: real LLM mode

Agents run in a deterministic offline mode by default (no key needed, fully reproducible). Setting
`ANTHROPIC_API_KEY` (see `.env.example`) switches `AgentRuntime` to a real Anthropic Messages API
call instead. This path is implemented but has not been exercised against the live API in this
environment — see RISKS_AND_TRADEOFFS.md. Never commit a real key; `.env` is gitignored.
